# Salmon standalone concept WIP

Portable, self-contained version of the Salmon `/reference` concept.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production build

```bash
npm run build
npm start
```

Everything required by the concept lives in this directory: application code,
the phone preview, fonts, images and video assets. It does not import files from
the parent Salmon website.
